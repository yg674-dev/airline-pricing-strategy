# Airline Pricing Strategy — A Framework Analysis

MBA strategic-pricing analysis of the US airline industry, April 2026.

## The argument

The base ticket fare stopped being the product. Margin now lives in ancillary fees, co-branded
credit-card loyalty partnerships, and premium cabins increasingly bought by leisure travelers
trading up — so airlines are no longer optimizing a fare, they are running a portfolio of
revenue streams that each need a different pricing logic.

Spirit's Chapter 11 filing in late 2024 is the period's defining event and the paper's pivot:
it shows pure price competition has a structural ceiling in this market, and that experience,
reliability, and loyalty buy pricing power a low base fare cannot overcome.
